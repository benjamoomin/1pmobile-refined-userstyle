# 1pmobile refined

A full modernisation project for [1pmobile.com](https://1pmobile.com) — focusing on cleaner styling, modern UI elements, and mobile optimisation.

## 🚀 Installation

### 1. Install a Userstyle Manager
Choose the extension for your browser:
*   [**Chrome / Brave / Edge**](https://chromewebstore.google.com/detail/stylus/clngdbkpkpeebahjckkjfobafhncgmne) (Stylus)
*   [**Firefox (Desktop & Android)**](https://addons.mozilla.org/en-GB/firefox/addon/styl-us/) (Stylus)
*   [**Safari (iOS / macOS)**](https://apps.apple.com/us/app/my-styles-custom-website-look/id6766115872) (My Styles) 
    *   *Note: Compatibility with "My Styles" is currently **untested**. Use at your own risk!*

### 2. Install the UserStyle
Once your manager is installed, click the button below to add the theme:

[![Install directly with Stylus](https://img.shields.io/badge/Install%20with-Stylus-00b48f?style=flat&logo=stylus&logoColor=white)](https://github.com/benjamoomin/1pmobile-refined-userstyle/raw/refs/heads/main/1pmobile-refined.user.css)

### 3. Select a Colour Theme
After installation, you can customise the colour theme to suit your preference:
1. Open your userstyle manager extension
2. Find "1pmobile refined" in your installed styles
3. Click the settings/options icon to access theme settings
4. Choose your preferred colour theme from the available options
5. The changes will apply immediately to 1pmobile.com

## 🛠 Features
- **Modern UI:** Updated border radius, spacing tweaks, and colour refinement.
- **Clean Design:** Removed clutter for a more focused experience.
- **Mobile Friendly:** Fixed layouts for better viewing on phones.
- **Data Usage Gauge:** Enhanced circular gauge replaces the default horizontal progress bar.
- **Selectable Themes:** Choose from multiple colour themes to match your preferences.
    *   *Note: Dark themes are currently in **beta**. Some elements may require additional refinement.*
